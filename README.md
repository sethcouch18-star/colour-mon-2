# Colormons (Cobblemon 1.8.1, Fabric 1.21.1)

## Build without installing anything (GitHub)
1. Make a free GitHub account, create a new repository, click "uploading an existing file" and drag in everything from this zip (keep the folders, including .github).
2. Open the Actions tab. The "Build mod" job runs automatically (or press Run workflow).
3. When it turns green, open the run and download "colormons-jar". Unzip it to get colormons-1.0.0.jar.

## Build on your PC
Install Java 21 (Temurin) and Gradle 8.14, then run `gradle build` in this folder. The jar is in build/libs/.

## Install
Put colormons-1.0.0.jar in your mods folder next to Cobblemon 1.8.1, Fabric API and Fabric Language Kotlin.
In game: look at a Pokemon, press C.
